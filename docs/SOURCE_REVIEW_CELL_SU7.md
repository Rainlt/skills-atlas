## 用途与核对范围

将 PNG、JPEG、WebP 科研图重建为可编辑 PPTX 或 Illustrator 图形与文字；也提供已认可 SVG 的后处理入口。例如把论文中仅有位图的框图转成可继续改标签、颜色和布局的文件。

已阅读固定版本的 README、实际 SKILL、Python 图片入口及平台说明。入口先调用小描适配器取得 SVG，再按文字清单恢复可编辑文字，最后进入输出后端；图像去字需要助手配合图像编辑模型，不由图片入口脚本单独完成。

这是用途、来源、目录和依赖核对，没有安装软件、执行上游脚本、同步依赖、上传图片或完成真实转换，不标成任务已跑通。主技能目录清单与 Git 树指纹一起进入正常索引校验。原有 17 个来源固定版本保持不变。

## 收费与安装边界

- 仓库标注 MIT；这是代码许可线索，不表示第三方服务免费。核心图片路径识别使用小描 API Key 与额度；[服务官网](https://xiaomiao-ai.com/)在本次核对时标注路径识别成功首次领取为 1 额度，具体套餐和费用在实际使用时再核对。图像模型和可选处理另计。
- 官方安装还会包含独立 cell_no_ai，并在安装及任务开始时同步其官方主分支。它不是本次新增的第二个索引用途；记录为配套依赖。该依赖的可选收费处理不因下载或收录而获得调用授权。
- 单项下载只提供该技能目录与许可告示，不能当作整套服务、共享资源和绘图应用已经配置。保留官方安装入口与平台说明，实际使用前核对。
- Windows PPT 有桌面实例记录；Mac PPTX 主要通过共享文件 / 结构检查，Mac Illustrator 主要是模拟桥接测试。不得把这些状态写成本机实际转换验证。

## 与助手直接重绘的关系

可直接让当前具备视觉与代码能力的助手读取图片，整理文字和结构，再生成 SVG 或 PPT 图形。这是另一条实现路线，不等于把 cell_su7 的收费图片入口切换成“免费模式”。简单流程图可以先采用已有绘图能力；复杂曲线、孔洞、遮挡和精确位置需要逐项对照，未实测时不能保证任一路线更准。

本次作为“科研图片转可编辑图”用途收录，不替换科研工具箱现有默认组件，也不增加另一套相同用途的全局安装。以后依据真实任务效果决定保留、替换或退出，继续保留版本和原因。
