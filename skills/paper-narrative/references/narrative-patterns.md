# 六种视角与证据门槛

只读与当前材料相符的行。以下例子均为方法示例，不代表已发生的实验或公众号论文的复述。

| 视角 | 能成立时的论证链 | 关键证据与反证 | 证据不足时怎样降级 |
|---|---|---|---|
| 根因分析 | 可重复的失效 → 候选解释 → 区分解释的实验 → 针对性改变 → 预期现象变化 | 控制混杂、匹配比较、针对机制的干预或可识别分析；同时检查替代解释。单一模块消融只能说明模块影响，通常不够证明根因。 | 写“观察到/与……一致/提出解释”，补最能区分解释的实验；不要称“揭示唯一根因”。 |
| 挑战默认设定 | 有来源的常用设定 → 适用边界或反例 → 替代方案 → 同条件比较 | 用代表性相关工作证明该设定确实常用；排除数据、容量、算力或调参预算不等造成的优势。保留原设定仍占优的条件。 | 写特定条件下的替代方案或工程权衡；未做系统检索不写“首次推翻领域共识”。 |
| 理论解释 | 精确问题 → 显式假设 → 可核查命题及证明 → 推论 → 与实验的对应关系 | 核对证明、适用域和已有结论；说明理想化假设与实际模型的差距。形式化不自动构成新理论，定理也不保证假设外的性能。 | 写经验规律或待证明猜想；不能为增强故事虚构引理、证明或一般性结论。 |
| 基准诊断 | 现有评价遗漏 → 目标能力定义 → 数据/测量设计 → 有效性检查 → 失败分布与诊断 | 检查标注可靠性、覆盖与代表性、数据泄漏、公平预算、指标对应的真实能力及不确定性；报告子群/任务差异。 | 写受控诊断集或有限场景测试；人工构造的失败不能直接外推真实使用频率。 |
| 实际价值 | 具体使用者及约束 → 技术选择 → 可测效用 → 实施条件与代价 | 准确率只是可能的中间指标；部署效果需真实流程或明确的代理测量支持，并区分已测收益和预期收益。涉及临床/政策结论时需要相应专业证据。 | 写应用动机、潜在用途与验证计划；离线分数不能等同于改善健康、生态或公共政策。 |
| 统一方法 | 多任务的共同结构 → 共享机制或接口 → 跨任务验证 → 例外和总成本 | 公平比较专用方案和共享方案；检查任务覆盖、训练/推理成本、额外数据、隐藏的专用模块与失败任务。一个接口不等于一个机制。 | 写实现复用或有限任务上的统一，不写“通吃”；模块少也不自动意味着更优或成本更低。 |

## 两个选线例子

**只有性能表。** 用户提供两个测试集、一次运行的小幅提升，没有方差、机制干预或可比预算。当前可以组织“在所报告设置下的性能观察”，还不能用“定位根因”主线。先写有范围的结果段落；优先补基线匹配与重复实验，再按具体解释设计机制检查。不凭空补出显著性或数值。

**指标近似，成本下降。** 如果已有匹配精度的多次测量和完整成本记录，可围绕计算/存储权衡组织贡献。无需把它升级成理论突破；若部分任务精度下降，清楚给出相应范围和权衡。数据未经复算时保留“据提供的实验汇总”。

## 改变主线的条件

- 核心现象无法重复：缩小结论或先补复现。
- 干预同时改变其他关键因素：保留替代解释，不能锁定根因。
- 新基准不能区分目标能力和捷径：先修正测量或改写成探索性诊断。
- 统一方案在关键任务失效或总成本更高：保留例外，重新判断统一是否仍是主要贡献。
- 新证据反驳初始解释：更新主张及摘要，不为保留故事删改证据。

退出某条叙事路线是正常研究决策；不因此否定工程改进、复现、数据资源或负结果的价值。
