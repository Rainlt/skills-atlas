# 论文主线与证据组织

把已有研究组织为读者能检查的论证。叙事服从事实与证据；六种视角是选择工具，不是论文必须满足的模板，也不是录用概率模型。

## 从用户当前材料开始

- 已有主张—证据表、调研记录或结果时直接复用，只补决定当前主线的缺口。
- 已有初稿时先定位失焦处，再按用户要求局部修改。只改摘要不重写全稿；只做语言或格式处理时直接完成原任务。
- 只有想法、没有结果时，输出可检验的问题、假设和实验方案。把预期结果标为预期，不代写成已完成研究。
- 学位论文风格、期刊规范和用户选定结构优先。可在既有章节内改善论证，不擅自改用另一种文体。

## 先判断材料能支持什么

用已有记录或一张小表对应：**主张 → 证据位置 → 证据状态 → 成立条件/反例 → 必要补证**。证据位置可以是用户给出的表、图、段落或实验文件；没有读取原始数据时注明仅据用户汇总，不能写成已复算。

区分直接观测、在条件下的推断、待检验假设、已被反驳的解释。相关性与一般消融不能自动升级为根因或因果证明；单次小幅涨点不能直接称稳健提升。数字、引文、首创、获奖和领域共识均需具体依据。

## 选择一条能成立的主线

按需读 [六种视角与证据门槛](references/narrative-patterns.md)。先考虑最贴合材料的少量候选，选择一条主线；只有另一个视角提供不同且已有支持的贡献时才作辅线。

| 视角 | 最关键的问题 |
|---|---|
| 根因分析 | 失效从哪里来，证据怎样排除其他解释？ |
| 挑战默认设定 | 哪个有出处的常用设定，在什么条件下可以被替代？ |
| 理论解释 | 哪个明确的经验现象，由哪些假设下的结果解释？ |
| 基准诊断 | 现有评价漏掉了什么，新测量怎样证明测到了它？ |
| 实际价值 | 谁受什么约束影响，技术改善是否能转化为实际效果？ |
| 统一方法 | 哪些任务共享同一个有效机制，整体代价和例外是什么？ |

没有足够证据支持任何一种时，采用如实的性能权衡、经验观察、复现或负结果主线。可以把未成立的视角转成后续验证方案，不能硬造“反直觉”“根因”“统一理论”或社会影响。

用自然语言说清当前主线，例如：“在【范围】内，已有方案的【具体问题】影响【任务目标】；我们的【改变】由【证据】支持，结论限于【条件】。”按实际论文写法调整，不强制填空，不追求戏剧化标题。

## 让论证决定结构和验证

围绕读者需要回答的问题安排材料：问题是否存在 → 原解释或设定哪里不足 → 方法为什么针对该问题 → 结果支持了什么 → 边界在哪里。用户已有合理结构时在原结构内完成，不固定章节数或段落数。

- 每个贡献对应必要的比较、测量、证明或反例；每个主要实验说明它支持哪项主张。
- 优先补会改变主结论的证据。区分必要补证与可选扩展，不为追求“故事完整”扩成无边界实验清单。
- 指标比较保持数据、预算、基线、方差与评价口径一致；无法比较时说明差异。需要复算时转入当前环境的数据分析流程。
- 结果与预想不一致时收缩或更换主线，保留负结果及替代解释；事后探索明确标注，不冒充预先提出的假设。
- 理论条件、适用范围和重要限制放在其所约束的主张附近。不要用空泛自贬替代具体限制，也不要以突出贡献为由删掉不利结果。

## 交付到用户要求的终点

按任务提供必要的主线判断、简短证据对应表、段落/章节安排和待验证事项。用户要求写作时继续给出实际改写稿，不能只交模板或建议；材料不足时写出能支持的部分，留下明确缺口。

完成前检查：标题与摘要是否强于证据、各项贡献能否追到材料、是否人为制造领域共识或反直觉、是否隐藏了关键失败、条件与数字是否被改动。

此技能只补论文论证组织：现有写作技能负责正文与文体，引用核查和结果复算按缺口调用，共用已有记录，不另起一条科研流程。

## 来源与使用界限

灵感来自 StudyAI / 人工智能学社《Story Is All You Need：扒透35篇顶会最佳/杰出论文的叙事密码，我们找到了六大范式》（2026-10-03），用户于 2026-11-04 提供正文。[原文链接](https://mp.weixin.qq.com/s/mnU8PE-6DZ38rJqHeOiSfQ)只作来源标注，运行技能不需要访问它。

本技能重新组织了方法，并补入证据门槛、反例与退出条件；不复制原文全文或图片。原文的论文名单、奖项归属、提升数字、审稿时间及“叙事导致获奖”等说法，不作为本技能已核实的学术事实。需要举真实论文例子时另查论文和会议原始资料。
