# 图片转可编辑 SVG

默认使用助手看图 + 本地描摹，不调用小描或其他付费识别服务。目标是可修改的路径与真正文字，保留原图和核对证据。当前路线是半自动重建，不能承诺一键还原所有图片。

环境：Python 3.11+、requirements.txt 中固定版本的 Pillow、NumPy、VTracer，以及可用的 SVG 渲染器或浏览器。助手负责看图和核对，脚本不含自动 OCR。

## 从当前材料开始

先查看原图，记录来源、许可、尺寸和用户要改的内容。有原始 SVG/绘图代码时直接编辑源文件。优先处理文字清晰、背景平整的框图和流程图；照片、显微图、渐变遮挡文字不适合直接抹字描摹，应说明未恢复部分或选择局部重建。统计图不能从像素猜测精确实验数值。

创建独立输出目录，保留输入。不要读取同图的现成 SVG 再把它称为图片重建测试。

## 执行

1. 用 `scripts/prepare_runtime.py --python <Python3.11+>` 准备或复用隔离环境，返回可用 Python 路径。依赖不装进全局；首次从 PyPI 安装，转换过程不联网。
2. 用该 Python 运行 `scripts/vectorize.py inspect <图片>` 查看尺寸。助手看原图逐行核对文字、标记文字框，写清单；格式见 [文字与位置清单](references/manifest.md)。不确定字符先核对，不把助手看图说成自动 OCR。
3. 运行 `scripts/vectorize.py rebuild <图片> <清单.json> <新输出目录>`。保留输入，输出纯描摹基线，按文字框取背景色清理文字，再本地描摹几何并恢复 `<text>`。背景混杂时停止，调整框或局部恢复背景后再试，不自动转付费接口。
4. 查看 `cleaned.png`，确认没有擦掉边框、箭头或曲线。若有，修正清单后换新目录重跑。渲染 `editable.svg`，与原图等比例并排及局部放大检查：标签、上下标、连线、箭头方向、颜色、模块数量和位置。
5. `scripts/vectorize.py audit <SVG> <清单>` 检查文本与清单一致、无嵌入位图。用 `edit` 将一处文字与一路径颜色改到新文件，重新渲染确认变化范围。目标 ID 来自本图 SVG，不固定套用其他图片的 ID；详见 `edit --help`。

可选 `scripts/render.cjs <SVG> <PNG>` 使用已有 Node.js + sharp，通过 `NODE_PATH` 指向模块。没有 sharp 时用浏览器查看，不因缺少预览工具重装办公软件。

## 交付与边界

交付 SVG、预览、原图来源、文字清单与 `report.json`，说明实际完成和未恢复部分。逐图核对后才能称为已验证；脚本计数、像素相似度不能证明科学语义正确。

- `<image>` 嵌图不能称为纯矢量；文字轮廓路径也不等于可改字文本。
- 部分连线仍可能是复合路径，不保证每根箭头独立成对象；不要盲目拆路径，可能填黑原本孔洞。
- 字体、字距、抗锯齿与曲线可能有差异，按预览调整清单中的字体和位置。携带字体需先核对许可，不捆绑任意本机字体。
- 默认交付 SVG。只有确实重建并检查原生形状与文字后才称作可编辑 PPTX，插入整张图片不算。

已验证案例和限制见 [验证记录](references/validation.md)，无需每次加载。
